# Independent export parser smoke

The smoke fixture is generated by the real TypeScript SM/SSC serializer and contains only synthetic chart data. It covers escaped colons, semicolons, and backslashes in metadata; two song BPM segments; a stop; time signatures; and chart-specific SSC offset and BPM overrides.

From `frontend/`:

```text
node scripts/export-smoke-fixture.mjs /tmp/stepper-export-smoke
../../audit-venv/bin/python scripts/check-export-with-simfile.py /tmp/stepper-export-smoke
```

The audit environment uses the independent PyPI package `simfile==2.1.1`. Because its `fs` dependency still imports `pkg_resources`, the environment also pins `setuptools<81`.

Result on 2026-09-11: strict parsing passed for both formats. Both preserved the escaped title `Escaped: title; \\ test`, artist `Artist: A; B`, global offset −0.125, BPM changes 120→180, the beat-8 stop, one chart, and four step rows. SSC additionally preserved the chart's effective offset 0.25 and BPM changes 150→200. SM correctly used song timing because that format has no chart timing block.

The sibling Stepper `ChartParser` independently produced the same effective timing and metadata values before this third-party check.
